DentalFlow V7.5.1 — Smart Input Enhancements

Based on the stable DentalFlow V7.5.1 Smart Input FIXED foundation.

Updates in this build:
- Patient fields across Clinical Visit, Treatment Plan, Billing, Appointment, Reminder and Patient Record now use type-first Smart Patient Input instead of select/drop-down menus.
- Existing patient names appear as suggestions while typing.
- A new patient can be added directly from the patient input.
- Long-pressing a Smart Input suggestion offers removal from suggestions; this does not delete the underlying patient/clinical record.
- Clinical Examination / Diagnosis / Treatment Problem / Action pickers now support custom options.
- New Problem / Action options can be added directly from each picker.
- Long-pressing a custom Problem / Action option allows deletion of that custom option.
- Existing dental data/localStorage key retained.
- No external libraries.

Note: fixed/default clinical options remain protected; only custom options are deletable.
